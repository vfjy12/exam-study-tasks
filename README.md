# 漫游与学习任务联动更新

同时启用漫游 0.6.2 与学习任务 0.2.0。在学习任务视图的“联动漫游的任务”选择一个已创建题单，空项关闭。仅该任务中已有题目会更新：蒙题提交且有选项、考试交卷且有选项时标记已作答；精读标记完成或取消同步到精读字段。任务完成和老师分析已读不自动变更。不回填升级前记录。没有启用任务插件时漫游照常运行。四类记录仍独立。原文档中的“全手动”描述适用于旧版。界面显示更新可能需重新选择任务。

静态及模拟测试通过，Obsidian/iPad 运行尚未验证。
# 考公学习任务 0.1.0

独立手动记录插件。创建固定题单，分别记录已作答、任务完成、精读完成、老师分析已读。数据保存在“学习任务”目录 Markdown 的 JSON 区块，其他备注不参与替换。通过 vault.process 读取最新任务并仅修改单个进度字段；缺失题目显示提示、不删除记录。按文件路径关联，重命名后需手动修正任务数据，未实现稳定题目 ID 迁移。

安装到 .obsidian/plugins/exam-study-tasks/，重启并启用。命令“打开学习任务”，新建任务粘贴每行一个库内路径或笔记双链。创建后回到任务下拉列表选择新任务；同题同类型操作以最后一次写入为准，不具备跨设备分布式锁。

目前不自动接收漫游作答、不自动写回题目 intensive_status、不逐老师区分阅读记录、不提供计划日期/调度、表格筛选题单或历史统计。不能替代完整学习调度规划。仅保存最近布尔状态，没有作答选项及多次学习历史。保存的是正式学习记录，不按缓存清理。语法和进度更新模拟测试通过，Obsidian/iPad 实机未验证。
